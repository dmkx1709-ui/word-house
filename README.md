# 单词小屋 · Word House

给四年级小朋友的单词游戏：**答对一个词赚一块砖，用砖块买家具，把一间小屋慢慢装成自己的样子。**

## 怎么玩

- 点 **开始今天的小任务**：先认识新词，再做题（听音选义 / 看义选词 / 拼字母）
- 答对 +1 🧱，答错不扣命，等会儿还会再出现一次
- 去 **家具店** 买喜欢的东西，回小屋拖到墙上或地上
- 点房间里的家具，会读它的英文名；点猫咪会喵，点钢琴会响
- 点窗户换天空（白天 / 黄昏 / 夜晚），点串灯开关灯，墙上的钟走真实时间
- 单词按间隔重复自动安排复习：10 分钟 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天

## 在 Mac 上启动

最简单的办法：双击 `start.command`。

或者手动运行：

```bash
cd /Users/dmkx1709/word-house
ruby -run -e httpd . -p 8766
```

然后打开 <http://127.0.0.1:8766/>。

## 在 iPad 上用

1. iPad 和 Mac 连同一个 Wi-Fi
2. Safari 打开 `http://192.168.5.35:8766/`（Mac 的局域网地址，换了网络要重新看）
3. 点分享按钮 → **添加到主屏幕**，之后就像 App 一样全屏打开
4. 注意：Mac 上的服务要一直开着；关掉终端窗口就停了

> 想要出门也能玩、不用开电脑，需要把它部署到网上（GitHub Pages / Netlify 之类）。
> 需要的时候可以让 Claude 帮你部署。

## 给家长

- **加词**：设置 → 导入她的词表，每行 `apple,苹果,🍎`，中文和表情可省略
- **每天新词数**：设置里可以调 4–15 个，默认 8 个
- **从第几课开始**：她学过前面的课的话，在设置里把“新词从第几课开始”调到当前课
- **备份 / 换设备**：设置 → 导出备份，会下载一个 JSON 文件
- **重新开始**：设置 → 重新开始（会清空进度）
- 进度存在浏览器本地（localStorage），不上传任何服务器，也没有广告和账号

## 单词

内置《新概念英语第一册》**第 1–35 课**的单词（约 280 个，来自家长提供的 5 页单词表）。

- 按课次顺序出现：第 1–10 课为 1 级，第 11–20 课为 2 级，第 21–35 课为 3 级
- 第 24 课的 `cigarette`（香烟）没有收录
- 同形不同义的词（`right` / `open` / `shut` / `empty` / `clean`）保留为两个词条
- 原来的 176 个人教版常见词作为占位词库保留在 `js/data.js`，游戏实际使用的是 `js/nce-data.js`

如果她用的是别的教材，把词表按 `apple,苹果,🍎` 每行一个导进设置里即可；或者让我直接替换。
