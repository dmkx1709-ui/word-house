# 单词小屋 · Word House

给四年级小朋友的单词游戏：**答对一个词赚一块砖，用砖块买家具，把一间小屋慢慢装成自己的样子。**

## 怎么玩

- 每天最多 **3 轮**，每轮 **5 个新词**，体力 15；复习不耗体力但计入轮次
- 先认识新词，再打乱顺序做题（听音选义 / 看义选词 / 拼字母）
- 答对 +1 🧱，答错不扣命；答错的词走单独的 **10 分钟 → 1 天 → 3 天** 重学阶梯
- 每天有一次 **错题复习**（最多 5 个词，不占 3 轮/体力）
- 去 **家具店** 买家具；小屋可以扩建出客厅、书房、阁楼
- 点房间里的家具会读英文名；猫咪会喵、钢琴会响
- 点窗户换天空，点串灯开关灯，墙上的钟走真实时间
- 普通复习按间隔重复：1 天 → 3 天 → 7 天 → 15 天 → 30 天

## 在线版（iPad 直接用）

打开 <https://dmkx1709-ui.github.io/word-house/>，点分享 → **添加到主屏幕**。

- 不需要开 Mac；首次打开后可以离线玩
- 进度存在 iPad 本地（localStorage），不上传服务器
- 更新游戏不会清空进度

## 在 Mac 上本地运行（开发用）

双击 `start.command`，或：

```bash
cd /Users/dmkx1709/word-house
ruby -run -e httpd . -p 8766
```

然后打开 <http://127.0.0.1:8766/>。本地和线上是两份独立存档。

## 给家长

- **加词**：设置 → 导入她的词表，每行 `apple,苹果,🍎`，中文和表情可省略
- **从第几课开始**：她学过前面的课的话，在设置里把“新词从第几课开始”调到当前课
- **每天的学习量**：固定 3 轮 × 5 个新词 = 15 个；错题复习每天一次
- **备份 / 换设备**：设置 → 导出备份，会下载一个 JSON 文件
- **重新开始**：设置 → 重新开始（会清空进度）
- 进度存在浏览器本地，没有广告和账号

## 单词

内置《新概念英语第一册》**第 1–35 课**的单词（286 个，来自家长提供的 5 页单词表）。

- 按课次顺序出现：第 1–10 课为 1 级，第 11–20 课为 2 级，第 21–35 课为 3 级
- 第 24 课的 `cigarette`（香烟）没有收录
- 同形不同义的词（`right` / `open` / `shut` / `empty` / `clean`）保留为两个词条
- 原来的 176 个人教版常见词作为占位词库保留在 `js/data.js`，游戏实际使用的是 `js/nce-data.js`

如果她用的是别的教材，把词表按 `apple,苹果,🍎` 每行一个导进设置里即可；或者让我直接替换。
